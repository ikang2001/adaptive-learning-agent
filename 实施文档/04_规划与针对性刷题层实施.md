# 规划与针对性刷题层实施

## 1. 本层目标

根据：

```text
Student Model
+
School Model
+
Learning Efficiency
+
当前阶段
+
可用时间
+
Question Pool
```

生成：

- 7 天计划；
- 每日明确任务；
- 针对性题目组合。

---

# 2. Planner 不应该直接由 LLM 全权生成

推荐：

```text
确定性 Constraint Solver / Rule Engine
        +
LLM Reasoner
```

确定性负责：

- 每日时间容量；
- 题目数量；
- 题型比例；
- 已完成任务排除；
- 必修前置知识；
- 截止时间；
- 可用题目数量；
- 任务冲突。

LLM 负责：

- 解释优先级；
- 复杂冲突权衡；
- 计划文字组织；
- 特殊情况策略建议。

---

# 3. 优先级输入

可以先构造：

```text
PriorityFeatures
├─ school_weight
├─ mastery_gap
├─ error_recency
├─ error_frequency
├─ true_exam_importance
├─ forgetting_risk
├─ prerequisite_block
└─ stage_weight
```

第一版允许简单规则：

```text
高考频 + 低掌握 → P0
高考频 + 中掌握 → P1
低考频 + 低掌握 → P2
未学且属于前置知识 → 提升优先级
```

以后再换算法。

---

# 4. 7 天计划生成

输入：

```text
未来7天每天可用时间
学生效率估计
当前优先级
复习阶段
```

输出：

```text
WeeklyPlan
```

任务必须是明确完成单位。

错误：

```text
周一：学习根轨迹 2h
```

正确：

```text
周一：
- 复习分离点规则
- 分离点基础题 5 题
- 分离点中等题 3 题
- 历史错题二刷 2 题
```

并给：

```text
预计总耗时：100~130min
```

# 5. Practice Planner

## 5.1 选题目标

不能只追求“最薄弱”。

还要平衡：

- 薄弱点；
- 目标院校高频；
- 新旧知识交替；
- 难度渐进；
- 错题复现；
- 防止题型过拟合；
- 已做题去重。

---

## 5.2 典型题目组合

例如某学生：

```text
分离点：弱
出射角：弱
渐近线：中
```

可以：

```text
分离点基础题      4
分离点变式题      3
出射角基础题      3
根轨迹综合题      2
历史错题二刷      2
```

---

# 6. 难度自适应

规则示例：

如果：

```text
最近 5 道基础题正确率 > 80%
且耗时低于个人 p50
```

则：

```text
减少基础题
增加中等/综合题
```

如果：

```text
中等题连续错误
```

则：

```text
降低难度
+
检查前置知识
```

不要一直硬升难度。

---

# 7. 学习时间预算

用户提交：

```text
今天最多 2 小时
```

Planner 使用：

```text
历史任务速度
+
题目数量
+
任务类型
```

估算：

```text
理论复习       30~40min
基础题 5题     30~45min
综合题 2题     35~50min
错题复盘       15~25min
```

总预算不得明显超出可用时间。

---

# 8. 冷启动时间估算

没有历史效率时：

使用系统默认分位数。

例如：

```text
basic_question = 8min
medium_question = 15min
comprehensive = 25min
```

必须标记：

```text
estimate_confidence = LOW
```

随着用户反馈逐步替换默认值。

---

# 9. 避免计划震荡

不能今天错一题，明天整个周计划推翻。

建议：

```text
minor_adjustment
major_replan
```

Minor：

- 明日题量 +2；
- 难度降低一级；
- 加一个错题复盘。

Major：

- 顺延新章节；
- 插入专项强化日；
- 切换阶段；
- 重排后续 3~7 天。

---

# 10. 可持续优化接口

Planner 必须抽象：

```python
class PlanningStrategy:
    def build_weekly_plan(...)
    def adjust_daily_plan(...)
```

Question Selector：

```python
class QuestionSelectionStrategy:
    def select(...)
```

以后可以并行比较：

```text
rule_v1
hybrid_v2
ranking_model_v3
```

不改上层 API。
