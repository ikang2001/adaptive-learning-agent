# 学生画像与诊断层实施

## 1. 本层目标

持续估计：

> 学生在哪些知识点上会、不会、学得多快、错在哪里。

注意：

Student Model 是**估计模型**，不是绝对事实。

---

# 2. 冷启动

第一次使用时系统没有历史行为。

输入：

- 已学章节；
- 未学章节；
- 自评薄弱点；
- 最近错题；
- 可选初始测评；
- 目标院校；
- 当前复习阶段。

初始掌握度必须低置信度。

例如：

```text
mastery_score = 0.60
confidence = 0.25
```

而不是：

```text
mastery_score = 0.60
confidence = 1.00
```

---

# 3. 掌握度更新信号

后续至少考虑：

```text
题目是否正确
题目难度
是否看答案
部分得分
实际耗时
最近连续正确
最近连续错误
错题二刷
真题表现
模拟卷表现
时间衰减
```

第一版不必一次全用。

建议 MVP：

```text
correctness
difficulty
looked_at_solution
recent_streak
```

先跑通。

---

# 4. 学习效率模型

不要建一个全局：

```text
efficiency = 0.72
```

应该分任务类型：

```text
理论复习
基础题
中等题
综合题
真题题
错题复盘
模拟考试
```

进一步可按知识点做局部修正。

预测任务耗时时：

```text
global_task_type_estimate
+
knowledge_specific_adjustment
+
recent_speed_adjustment
```

输出范围：

```text
预计 90~120 分钟
```

不要假装精确到 103 分钟。

---

# 5. 错题诊断

## 普通情况

学生自己给出明确复盘：

```text
“分离点公式记错”
```

系统可直接记录为高置信证据。

## 模糊情况

学生只提交：

```text
这题错了
```

Agent 才进入诊断。

流程：

```text
题目
+
学生答案
+
标准答案
 ↓
生成错误假设
 ↓
查询知识点
 ↓
查询历史同类错误
 ↓
必要时检索讲义
 ↓
验证假设
 ↓
输出 ErrorProfile 更新
```

---

# 6. 证据驱动诊断

每个较重要的诊断结论保存：

```text
Diagnosis
├─ diagnosis_id
├─ hypothesis
├─ knowledge_ids[]
├─ evidence_refs[]
├─ confidence
├─ status
└─ model_version
```

状态：

```text
HYPOTHESIS
SUPPORTED
REJECTED
UNCERTAIN
```

如果证据不足：

> 不要强行输出“你不会某知识点”。

应该输出：

```text
当前证据不足，建议增加 3~5 道诊断题。
```

---

# 7. 前置知识诊断

例如学生连续在“分离点”错。

不能永远认定：

```text
分离点不会
```

可能真实原因：

- 开环极点零点概念混淆；
- 根轨迹存在区间判断错误；
- 求导计算错误；
- 多项式计算基础差。

因此知识树需要 prerequisites。

Agent 可执行：

```text
current_error
 ↓
check prerequisite knowledge
 ↓
search historical attempts
 ↓
diagnose upstream weakness
```

---

# 8. 画像更新频率

不建议每做一道题就全局重算。

可以分层：

## 实时轻量更新

- attempt 写入；
- recent accuracy；
- recent duration；
- streak。

## 每日聚合

- knowledge mastery；
- error profile；
- efficiency profile。

## 周期重算

- 每周重估长期 mastery；
- 评估旧错误是否已经修复；
- 遗忘风险计算。

---

# 9. 画像的可解释性

前端显示：

```text
根轨迹 / 分离点

掌握度：42%
置信度：中

依据：
最近 6 题正确 2 题
最近 3 次综合题均错误
真题正确率 33%
最近一次练习：昨天
```

不要只给一个神秘分数。

---

# 10. 后续算法可升级方向

按顺序考虑：

V1：
规则加权

V2：
指数平滑 + 难度修正

V3：
Bayesian Knowledge Tracing / IRT 思路

V4：
基于历史学生行为的预测模型

V5：
在线策略学习

关键是：

> 数据结构先稳定，算法以后替换。
